## 🇬🇧 English

This repository is a collection of projects and exercises from my data
science, machine learning, and cloud computing coursework — organized into
folders by topic and roughly by chronological order (earlier folders =
earlier/more basic work, later folders = more advanced work). **Each folder
has its own `README.md`** with a detailed breakdown of what's inside; this
file is just the index.

| Folder | What's inside |
|---|---|
| [`01-python-fundamentals`](./01-python-fundamentals) | Early Python exercises: OOP basics (classes, inheritance, abstraction, encapsulation), input validation, error handling, and a small ETL/API data pipeline for movie data. |
| [`02-pandas-data-analysis-and-statistics`](./02-pandas-data-analysis-and-statistics) | `pandas`-based data cleaning, preprocessing, and statistical analysis (mean, standard deviation, quartiles, IQR) on an online store dataset and a fitness tracker dataset. |
| [`03-data-visualization-and-reporting`](./03-data-visualization-and-reporting) | Jupyter notebooks turning data analysis into visual, business-style reports using `matplotlib`, `seaborn`, and `plotly` — ending with a Netflix market-research final project. |
| [`04-r-data-analysis-and-modeling`](./04-r-data-analysis-and-modeling) | R projects: multi-source data integration (CSV, Excel, MySQL), data tidying, `ggplot2` visualization, and linear regression modeling — including a Netflix IMDb-score prediction final project. |
| [`05-sql-python-movies-analysis`](./05-sql-python-movies-analysis) | MySQL database design and queries for a movies database, connected to from Python (`pandas`, `matplotlib`) for box-office analysis. |
| [`06-machine-learning-projects`](./06-machine-learning-projects) | Supervised machine learning text classification with `scikit-learn`: a product category classifier and a spam/ham message classifier, plus a car pricing dataset. |

**Related, separately hosted project:** [car-price-prediction](https://github.com/adizebic/car-price-prediction) — kept as its own repository.

### General notes

- Most projects are written with Bosnian/Croatian variable and comment
  names, since they were built as part of a Bosnian-language course — the
  README in each folder explains the logic and purpose in English.
- Some datasets are included directly in their folder so each project can
  be run standalone; others (like the Kaggle-sourced or cloud-hosted ones)
  are referenced by link inside that folder's README instead.

## 🇧🇦 Bosanski

Ovaj repozitorijum je zbirka projekata i vježbi iz mog kursa iz data
science-a, mašinskog učenja i cloud computing-a — organizovana u foldere po

osnovniji rad, kasniji folderi = napredniji rad). **Svaki folder ima svoj

| [`02-pandas-data-analysis-and-statistics`](./02-pandas-data-analysis-and-statistics) | Čišćenje podataka, preprocesiranje i statistička analiza (prosjek, standardna devijacija, kvartili, IQR) pomoću `pandas`-a, na skupu podataka online prodavnice i fitness trackera. |
| [`03-data-visualization-and-reporting`](./03-data-visualization-and-reporting) | Jupyter sveske koje pretvaraju analizu podataka u vizuelne izvještaje poslovnog stila koristeći `matplotlib`, `seaborn` i `plotly` — završavaju finalnim projektom istraživanja Netflix tržišta. |
